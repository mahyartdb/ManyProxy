## Overall Impression

Gut reaction: an honest-copy instrument with disciplined state color and rare shortcut visibility — solid Operate bones. What doesn't work is selection grammar (two overlapping models) and detail-pane density (eleven controls above the fold line, endpoints pushed into a scroll box). ## What's Working

1. **Honest copy as UI.** Toasts refuse clean sweeps, confirms and failures name rows, clipboard carries binds never secrets. Builds the exact trust a local-only promise needs.
2. **Signal-only color discipline.** Blue is selection, green/red is serving, black is primary action; everything else ink/paper/gray. The only reason ledger-density rows stay scannable.
3. **Shortcut visibility.** Kbd chips on Add/Start/Stop/Test/Import with full `Name (Key)` on accessible names and tooltips. Operate tools live or die by this.

## Priority Issues

- **[P0] Selected-row vs. checked-set collision.** The blue-wash selection (F5/detail target) coexists with the checkbox bulk set under near-identical highlight language. Alex bulk-deletes the wrong rows; Nadia cannot predict what Start will touch. Fix: one grammar — wash for selection only, checked rows get a rim plus count chip, bulk label always `N checked (of M visible)`, detail header echoes `Acting on: <name>`. Suggested command: `harden`.
- **[P1] Detail pane is two toolbars stacked in 240px.** Manage row plus operate row sit above Endpoints/Health inside a 240px scrolling cap, so endpoints — the pane's reason — start below the fold. Fix: collapse the manage row into a row menu, keep Start/Stop/Test/Ping/Logs plus Copy URLs inline. Suggested command: `distill`.
- **[P1] Add/Edit Params JSON is a cliff.** The primary creation path demands hand-written sidecar config JSON with only Format/Template/Validate as aids; one typo becomes a dead endpoint with shard-sidecar error text. Fix: protocol picker scaffolding a labeled mini-form with JSON as an Advanced disclosure and inline validation. Suggested command: `onboard`.
- **[P2] Grouping hid the library verbs.** Import/Export/Subscriptions/Start-all/Test-all now cost open-menu plus aim; the drop hint is the only persistent import affordance. Fix: keep Import as a persistent fifth button and add a visible search shortcut. Suggested command: `clarify`.
