## 2. Outcome and proof

One glance tells: which endpoints serve, which are dead, what is selected versus checked, and what Start will touch. Success = Nadia starts her first endpoint without reading anything twice.

## 3. Selected direction: The Signal Box, encompassing

Owning world: railway signal-box panel. Library rows are track circuits (lamp, nameplate, numbers, badge) on paper-white ground with slate-ink track lines; toolbar is a lever frame of guarded throws; detail is a block shelf of instruments; dialogs are ruled train orders. Restrained palette, scene-forced light ground, platform sans with small-cap plate labels and tabular numerals.
Chartered inside it (one world, three named disciplines):
- **Timetable discipline** — fixed-cell state marks and single-size rank by weight and case for all rows.
- **Split-flap discipline** — live ranked rows; state changes cascade visibly inside the 250ms Operate budget.
- **Mosaic discipline** — detail shelf packs endpoints/health/usage as ruled modules, never stacked toolbars.
Carried raises: Row-Numbers (no numberless rows), Across-the-Room (selection reads from the desk away), One-Geometry (one exact row anatomy).
Standing alternative: the category-standard gray ledger, available on request, never the default.
