## Problem Statement

ManyProxy already serves N proxy configs at once, each on its own loopback endpoint (`bind:port`, default `127.0.0.1` + free port in `10801–10999` spill `18081–18380`). But the shell around that core is still first-generation: a 5-throw lever toolbar plus four differently-shaped menus, single-column Add/Edit forms where AnyTLS stacks two password inputs and glues forced-TLS to dial panels with shared ids, an inspector that repaints header + Endpoints on all three tabs, a status bar with three evidences of one fact, single-vs-subscription imports behind one dialog, and no honest per-connection view. Throne (open-source, battle-tested, Qt) already solved the adjacent problems — per-type bean editors, `EditAdvanced` dial/TLS disclosure, `RawUpdater`/`GroupUpdater` intake, identity-keyed subscription diff, `Manage Groups` + `GroupItem` rows, Selected-vs-Group test split, column sorting/filtering, runtime/traffic stats — for a single-tunnel VPN. The user wants that rigor extracted and adapted to a multi-exit library, keeping local-only guarantees, with dark-default theming.

## Solution

Polish the incumbent Signal Box world (no new visual language) while restructuring inside it: (1) top bar becomes `PROGRAM | SETTINGS | GROUPS | ROUTING | TOOLS` + round global Start/Stop; (2) Settings restructures to `Basic (+Appearance) | Routing | Preset | Hotkey`; (3) middle keeps cards, adds row-targeted right-click + double-click Edit; (4) Edit adopts Throne grouping (`Common + <Type> + Network/TLS/Mux`, right `TLS Security + Camouflage`, second `Advanced` dialog for Dial + TLS extras); (5) bottom dedupes header/Endpoints above tabs and gains `Logs | Connections (honest 5-col) | Traffic (per-exit)`; (6) intake splits single-config (PROGRAM) vs subscription (GROUPS) with file/drop/deeplink parity; (7) parsers, subscription diff, group ops, test semantics, routing manager, stats dialogs, and table mechanics lift Throne behaviors adapted to N exits; (8) theme becomes Dark-default + Light + System-follow via tokens only.

## User Stories

1. As a library owner, I want a `PROGRAM` menu holding app lifecycle plus single-config intake, so that New/clipboard/file/QR/drop/deeplink live in one predictable place.
2. As a library owner, I want `From clipboard (Ctrl+V)` to accept one link or bare `http(s)://` via a chooser (add-here / new-subscription / HTTP-proxy-profile), so that pastes never silently misroute.
3. As a library owner, I want `From file(s) (Ctrl+O)` with All-files-first filter, 50MB cap, and content-sniff (QR-decode, BOM/UTF, NUL-reject), so that extension-less configs and QR screenshots import.
4. As a library owner, I want drag-drop anywhere (files → batch single result, text → single path) and `manyproxy://add|addsub` open-with handling, so that OS and browser handoffs work.
5. As a subscription user, I want `GROUPS` to own subscriptions only (Manage / Add-subscription-group / Edit-current / Delete / Update-current `Ctrl+U` / Update-all with confirm), so that group ops never confuse row ops.
6. As a subscription user, I want refresh to diff by identity key with in-place update (id/port/traffic kept), reorder to remote order, `[+]Added / [~]Updated / [-]Deleted` counts plus `[=] Still in use` for running rows, log always and popup only on manual single refresh, so that refresh is trustworthy.
7. As a subscription user, I want renames preserved, duplicates avoided, and last-good members kept on fetch failure, so that a bad refresh never wipes my edits.
8. As a subscription user, I want `Basic | Subscription (N)` group rows showing `Last update | Used / Remain / Expire` from `Subscription-Userinfo` plus per-row Update button, so that quota state is visible.
9. As a desktop user, I want a round global Start/Stop (play↔stop morph, `Connecting…/Stopping…` spinner, LAN-confirm gate, busy guard, honest toast) meaning Start-all / Stop-all, so that one throw controls the room.
10. As a desktop user, I want per-row Start/Stop/Test/Ping kept in cards + right-click + bulk bar, so that global never removes row control.
11. As a desktop user, I want footer/status to aggregate (`N live · M dead`, `:port [:port…] [+N]`, `↓↑` totals, `engine running · N endpoints`), never naming one profile, so that N-exit truth is honest.
12. As a card user, I want single-click select, double-click Edit that row, and right-click opening a row-targeted menu (`Start/Stop/Test/Ping/Copy URLs/Edit/Duplicate/Delete/Reset traffic|usage/Move to group`), so that I stop fighting selection-targeted menus.
13. As a card user, I want `Clone` alias gone and bulk staying start/stop/enable/move/delete (no bulk duplicate v1), so that Duplicate means one thing.
14. As an editor, I want Add to show Type combo and Edit to lock protocol, with `Common (Type/Name/Address/Port + Advanced Settings button)` + `<Type>` box + `Network/TLS/Mux` boxes left and `TLS Security + Camouflage` right, so that AnyTLS-style stacking disappears.
15. As an editor, I want `Advanced Settings` to open a second small `Dial Fields + TLS extras` dialog (direct-to-object, no extra validation), so that rare knobs stop crowding the main form.
16. As an editor, I want no duplicate password inputs (guided identity vs inner password deduped), port-budget readout kept, and inline validation keeping the dialog open, so that saves fail loudly and locally.
17. As an editor, I want Throne placeholders/defaults/tooltips (`xudp`, `bbr`, `1420`, Warp-gen hints, `Not Set/Already Set` cert labels, `*` required marks), so that empty-field behavior matches a known-good reference.
18. As a settings user, I want `Basic | Routing | Preset | Hotkey` sections with ROUTING menu linking into Routing, so that there is one copy of each control.
19. As a settings user, I want `Basic > Appearance` Radio `Dark (default) / Light / System→Windows AppsUseLightTheme`, persisted and live via theme tokens with no restart, so that ambient-light choice is respected.
20. As an inspector user, I want header + Endpoints rendered once above tabs instead of 3×, with failure evidence inside the minimum pane, so that tab switches stop repainting identical blocks.
21. As a connections watcher, I want a bottom `Connections` tab with honest v1 columns (`Destination / Exit row + bind:port / Row protocol / Traffic ↓↑ / Session Δ`), click-copies dest, sorts by traffic, filters to selected row, probes excluded, so that I see what flows where without fabricated protocol/outbound/rate.
22. As a traffic watcher, I want a per-exit aggregate graph (not fake Proxy-vs-Direct) plus `Traffic Stats (period 24h/7d/30d/90d + stacked bars + By Profile)`, sourced from existing per-row totals + clash poll, so that heavy exits surface fast.
23. As a runtime watcher, I want `Tools > Runtime Stats` (process CPU/RAM mini-charts, active conns, speeds, next sub/route update, DB sizes, uptime, running config + ping), so that health checks have one screen.

As a tester, I want Selected-vs-Group split for `URL Test / Speedtest (mode + timeout) / Resolve Out-IP`, plus Resolve-Domain rewrite (row save + group-with-confirm), Throne latency colors and result strings, batch `100` / poll `200ms` / conc `10` / url-timeout `3000` / speed-timeout `5000`, `Stop Testing`, and group `auto-clear-unavailable` prune option, so that batch testing behaves predictably.

31. As a local-only user, I want no TUN / system-proxy / OS-DNS / Hijack-Redirect / Warp / elevation / silent-download paths introduced by any of the above, with existing no-system-mutation scans kept green, so that adoption never breaks the core promise.

## Implementation Decisions

- Modules touched: toolbar/menus shell + tray; Settings dialog sections; library cards + row menu + bulk bar; inspector tabs + status bar + new Connections/Traffic tabs + Logs filter; Add/Edit forms + Advanced dialog; intake paths (paste/file/drop/deeplink/QR-batch split); subscription refresh + diff + scheduler display; group dialogs + tab context; parsers for `mieru, juicity, trusttunnel, shadowtls, ssh, direct, json://`, WG-file sniff, brace-aware multiline split, base64-recurse, Clash `xhttp→xray` rule, Xray `freedom/blackhole` drop (`chain/autoselector/custom/extracore/tailscale` excluded); test/speed/resolve runners; preset/route manager; runtime/traffic stats; theme tokens + Appearance persistence.
- `PROGRAM` = single-config + app lifecycle; `GROUPS` = subscriptions + group ops; `ROUTING` = preset chooser + Open Manager link; `TOOLS` = stats, update checker (disabled without updater binary), palette entry points. `Add/Import/Test` do not disappear — they move into this scheme.
- Global Start/Stop = Start-all / Stop-all (LAN-confirm, busy guard, honest toast, spinner states, only Idle/Running clickable); per-row control stays in cards/menus/bulk. No `remember-last-proxy` single memory; footer aggregates.
- Edit keeps protocol-lock on Edit, port-budget readout, save-gate + store-gate validation (stricter than Throne soft validators); adopts Throne placeholders/defaults/labels and `Not Set/Already Set` cache pattern; kills guided-identity vs inner-password duplication.
- Subscription diff keys on `type + ExportIdentity`, full-link `ent_key` for add/delete; in-place outbound swap keeps id; reorder to remote order; sticky running rows kept with `[=]`; popup only on manual single refresh gated by show-changes setting; rename preservation + last-good-on-failure layered on top.
- Connections v1 renders only stored fields (`dest`, `row_id` join, row protocol, cumulative `rx/tx`, session Δ); wire `network/chains/rule` + true `/s` rate deferred to parser + timestamp phase 2. Traffic graph = per-exit aggregate; no Direct line until presets emit per-rule decisions.
- Theme: existing token names and signal meanings frozen; frontmatter expands to `dark:` + `light:` palettes; app code stays zero-hardcoded-color; `Theme::change` at startup + live on switch; System follows Windows light-theme flag.
- Throne exclusions (non-negotiable): TUN/stack/MTU/IPv6/strict-route/private-bypass/auto-redirect, System Proxy/DNS toggles, Hijack DNS/Redirect, Warp keys/endpoint, elevation/restart-with-DNS, `Fwpm`, `url_scheme` self-heal writes beyond additive open-with (open-with itself allowed as additive), telemetry beyond user-initiated fetches/probes, silent binary downloads, `disable-tray` removal of required tray surface.
- Conflict note: repo `spec.md` Non-goals currently bans a routing-rule editor; Q19 approves a preset/route manager. Adopting Q19 requires amending that non-goal to allow a local-only preset editor with `proxy|direct|block` (still no TUN/system/DNS).

## Testing Decisions

- Good tests assert external behavior (menus open, toasts read, rows added/updated/deleted, endpoints serve, diffs count, themes switch) not widget internals.
- Modules under test: intake parsers (link fixtures per scheme incl. malformed/empty-password cases); subscription diff (added/updated/deleted/rename/sticky/failure-keeps-last-good); store traffic totals + port auto-assign + collision warnings; engine start-one/all + isolation map + clash poll attribution + LAN gates; health probes + history; UI ids/toasts/palette/tray/statusbar/inspector tab counts; theme token resolution dark/light/system.
- Prior art: existing 804-test suite patterns — `assert_no_system_mutation`-family scans (must stay green), import-grammar coverage, honest-toast assertions, TEMP-file hermetic stores, live sidecars only behind `MANYPROXY_SINGBOX_BIN` + `MANYPROXY_LIVE_CHECK/TRAFFIC` gates. New parser/diff/poll tests follow the hermetic TEMP pattern; UI assertions follow pinned `Button::new` id + toast-string style.

## Out of Scope

- Best-exit Auto-Selector engine (pool/build/validity/balance/country-filter/pinned + 9-col stats) — phase-2 epic with new engine + scheduler work.
- Per-connection wire parser expansion (`network/chains/rule` persistence + true `/s` rate timestamps) — phase 2 behind Connections v1.
- `chain / custom-full / custom-outbound / extracore / tailscale` intake as first-class add flows; `trusttunnel` beyond parse; Warp-bypass action; By-App traffic; dark-mode follow-up palettes beyond the dual Signal Box pair; QR screen-capture path (file-QR only v1); `Front/Landing proxy`, `Auto-clear`, `Remove insecure`, speed-traffic ledger, `disable_traffic_stats` kill-switch.
- Any system-proxy switching, TUN/interface, OS DNS rewrite, Hijack/Redirect, elevation/service/driver install, telemetry, silent downloads, auto-update replacing binaries.
